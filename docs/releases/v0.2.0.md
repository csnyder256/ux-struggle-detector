# ux-struggle-detector v0.2.0 — Clarus Heal self-hosting release

## What changed

- Docker Compose deployment with PostgreSQL, persistent data and an explicit schema setup step.
- Standalone production server and versioned browser SDK downloads.
- Audited tenant authorization, ingestion and detector boundary fixes.

## Install and upgrade

Back up PostgreSQL before upgrading. Existing installations must review schema changes rather than run the fresh-install setup command. Container defaults require authentication and ingestion keys. Existing legacy intervention rows remain intact; newly created rows carry tenant scope.

See [deployment instructions](../../DEPLOYMENT.md) and the attached checksums.
